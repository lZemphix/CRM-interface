# Отложенные ошибки

## UI-AUTH-001 — Первый символ после смены раскладки не вводится

date: 2026-10-07
status: deferred
target: before-release
tags: auth, login, input, keyboard-layout, windows

Reported:
В форме входа после смены раскладки первый введённый символ не появляется,
даже если текстовое поле сохраняет фокус и после смены раскладки сделать паузу.

Reproduction:
Сфокусировать поле на экране авторизации, сменить раскладку, выждать паузу,
напечатать символ; первый символ отсутствует. Сообщено пользователем,
независимое воспроизведение и причина пока не установлены.

Plan:
По явной просьбе пользователя только записать; исследовать и исправить ближе
к релизу. Auth-код в рамках оформления карточек задач не менять.
