- Backend и Flutter находятся в отдельных связанных репозиториях. Это осознанное разделение, а не попытка превратить backend в микросервисы.

## 2026-09-14 — Архитектурное понимание backend

time: unknown
type: discussion
tags: backend, sqlalchemy, repository, use-case
areas: application/, database/, web/

Summary:
Ретроспективный контекст, восстановленный 2026-09-14; точная дата исходного обсуждения неизвестна.

Details:
- Репозиторий отвечает за способ хранения и извлечения данных: SQLAlchemy, таблицы, `SELECT`, `INSERT`, загрузку связей.
- Use case отвечает за бизнес-действие и не должен знать названия таблиц и колонок. Для единого стиля утверждены классы use case с методом `execute`, даже если действие пока небольшое.
- DTO используются как типизированные снимки входных команд, запросов и результатов между слоями. Пользователь уже применял такой подход в других проектах через замороженные dataclass, не называя его DTO.
- FastAPI-схемы описывают HTTP-контракт, DTO — application-контракт, ORM-модели — хранение. Эти роли не следует смешивать.
- SQLAlchemy используется асинхронно. `AsyncSession` — единица работы с БД; транзакцией управляет use case, а repository выполняет операции через переданную сессию.
- Разделение на слои принято не ради усложнения, а чтобы application-логика не зависела от конкретной таблицы и транспорта.

Summary:

Один общий экземпляр `Dio` будет хранить `baseUrl`, таймауты, общие заголовки и позднее interceptors авторизации; repository каждого модуля получает этот клиент и знает только endpoints своего домена и преобразование JSON в DTO. Это признано ошибкой темпа обучения. Дальнейший сетевой слой разбирается последовательно на текущем коде пользователя с Python-аналогами; новая конструкция не должна появляться без предварительного объяснения.

Первый пользовательский вариант сетевого кода архитектурно направлен верно (`ApiClient` и `CustomersRepository` разделены), но на момент проверки содержит известные технические ошибки: `baseUrl` без схемы `http://`, опечатку `Acept`, пропущенную точку с запятой после конструктора repository и несоответствие результата `map()` объявленному `Future<List<dynamic>>`.
